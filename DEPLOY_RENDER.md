# Пошаговая инструкция по развертыванию на Render.com

## Преимущества Render.com

- **750 часов/мес бесплатно** (хватает на 24/7 работу)
- Автоматический деплой из GitHub
- Переменные окружения в панели
- Автоматические перезапуски при ошибках
- SSL сертификаты включены

---

## Шаг 1: Создайте аккаунт GitHub

1. Перейдите на https://github.com
2. Нажмите "Sign up"
3. Заполните форму регистрации
4. Подтвердите email

---

## Шаг 2: Создайте репозиторий на GitHub

1. Нажмите "+" в правом верхнем углу
2. Выберите "New repository"
3. Введите имя: `telegram-news-bot`
4. Выберите "Public" (для бесплатного тира)
5. Нажмите "Create repository"

---

## Шаг 3: Загрузите код на GitHub

### Способ 1: Через GitHub Web (простой)

1. На странице репозитория нажмите "uploading an existing file"
2. Перетащите все файлы из папки `telegram-news-bot`
3. Нажмите "Commit changes"

### Способ 2: Через Git (продвинутый)

Откройте терминал и выполните:

```bash
cd ~/telegram-news-bot
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/telegram-news-bot.git
git push -u origin main
```

---

## Шаг 4: Создайте аккаунт на Render.com

1. Перейдите на https://render.com
2. Нажмите "Get Started for Free"
3. Выберите "Sign up with GitHub"
4. Разрешите доступ к репозиториям

---

## Шаг 5: Создайте Worker Service

1. В.dashboard Render.com нажмите "New +"
2. Выберите "Worker"
3. Выберите "Build and deploy from a Git repository"
4. Нажмите "Next"

---

## Шаг 6: Подключите репозиторий

1. Найдите репозиторий `telegram-news-bot`
2. Нажмите "Connect"
3. Настройте параметры:
   - **Name**: `telegram-news-bot`
   - **Region**: Выберите ближайший регион
   - **Branch**: `main`
   - **Runtime**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`

---

## Шаг 7: Настройте переменные окружения

Перейдите в "Environment" и добавьте:

1. **BOT_TOKEN**:
   - Key: `BOT_TOKEN`
   - Value: Ваш токен из @BotFather

2. **CHANNEL_ID**:
   - Key: `CHANNEL_ID`
   - Value: ID вашего канала (например, `-1001234567890`)

3. **CHECK_INTERVAL** (опционально):
   - Key: `CHECK_INTERVAL`
   - Value: `1800` (30 минут в секундах)

4. **MAX_NEWS_PER_CYCLE** (опционально):
   - Key: `MAX_NEWS_PER_CYCLE`
   - Value: `5`

---

## Шаг 8: Запустите деплой

1. Нажмите "Create Worker"
2. Дождитесь завершения сборки (обычно 2-5 минут)
3. Проверьте логи на наличие ошибок

---

## Шаг 9: Проверьте работу бота

1. Откройте чат с ботом в Telegram
2. Отправьте `/status`
3. Бот должен ответить статусом

## Решение проблем

### Бот не запускается

1. Проверьте логи в Render.com
2. Убедитесь, что BOT_TOKEN и CHANNEL_ID установлены
3. Проверьте, что бот добавлен в канал как администратор

### Бот не публикует новости

1. Проверьте ID канала
2. Убедитесь, что бот имеет права на публикацию
3. Проверьте, что новости соответствуют ключевым словам

### Ошибки в логах

1. Перейдите в "Logs" в dashboard
2. Найдите сообщения об ошибках
3. Исправьте проблему и перезапустите

## Дополнительные настройки

### Изменение интервала

В Render.com измените переменную `CHECK_INTERVAL`:
- `900` = 15 минут
- `1800` = 30 минут (по умолчанию)
- `3600` = 1 час
- `7200` = 2 часа

### Изменение количества новостей

Измените переменную `MAX_NEWS_PER_CYCLE`:
- `3` = Меньше новостей
- `5` = По умолчанию
- `10` = Больше новостей
