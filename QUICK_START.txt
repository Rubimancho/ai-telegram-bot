================================================================
       БЫСТРЫЙ СТАРТ: РАЗВЕРТЫВАНИЕ НА RENDER.COM (БЕСПЛАТНО)
================================================================

Эта инструкция поможет вам запустить бота в облаке за 15 минут.

================================================================
                        ЧАСТЬ 1: ПОДГОТОВКА
================================================================

ШАГ 1: СОЗДАЙТЕ АККАУНТ GITHUB
-------------------------------

1. Перейдите на https://github.com
2. Нажмите "Sign up"
3. Заполните форму:
   - Email: ваш_email@example.com
   - Password: ваш_пароль
   - Username: ваш_логин
4. Подтвердите email
5. Готово!

================================================================

ШАГ 2: СОЗДАЙТЕ АККАУНТ RENDER.COM
-------------------------------------

1. Перейдите на https://render.com
2. Нажмите "Get Started for Free"
3. Выберите "Sign up with GitHub"
4. Разрешите доступ к репозиториям
5. Готово!

================================================================

ШАГ 3: СОЗДАЙТЕ TELEGRAM БОТА
-------------------------------

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте /newbot
4. Введите имя бота (например: "Мои Техно Новости")
5. Введите username (должен заканчиваться на bot)
6. Скопируйте ТОКЕН (строка вида 1234567890:ABC...)
7. Готово!

================================================================

ШАГ 4: УЗНАЙТЕ ID КАНАЛА
--------------------------

1. Откройте Telegram
2. Найдите @userinfobot
3. Перешлите ему сообщение из вашего канала
4. Скопируйте ID (число вида -1001234567890)
5. Готово!

================================================================
                     ЧАСТЬ 2: РАЗВЕРТЫВАНИЕ
================================================================

ШАГ 5: СОЗДАЙТЕ РЕПОЗИТОРИЙ НА GITHUB
----------------------------------------

1. Перейдите на https://github.com
2. Нажмите "+" в правом верхнем углу
3. Выберите "New repository"
4. Введите имя: telegram-news-bot
5. Выберите "Public"
6. Нажмите "Create repository"
7. Готово!

================================================================

ШАГ 6: ЗАГРУЗИТЕ КОД
----------------------

1. На странице репозитория нажмите "uploading an existing file"
2. Откройте папку ~/telegram-news-bot
3. Перетащите ВСЕ файлы в браузер:
   - bot.py
   - sources.py
   - config.py
   - requirements.txt
   - Dockerfile
   - render.yaml
   - .gitignore
4. Нажмите "Commit changes"
5. Готово!

================================================================

ШАГ 7: СОЗДАЙТЕ WORKER НА RENDER.COM
--------------------------------------

1. В dashboard Render.com нажмите "New +"
2. Выберите "Worker"
3. Выберите "Build and deploy from a Git repository"
4. Нажмите "Next"
5. Найдите репозиторий telegram-news-bot
6. Нажмите "Connect"
7. Настройте:
   - Name: telegram-news-bot
   - Region: ближайший регион
   - Branch: main
   - Runtime: Python 3
   - Build Command: pip install -r requirements.txt
   - Start Command: python bot.py
8. Нажмите "Next"
9. Готово!

================================================================

ШАГ 8: ДОБАВЬТЕ ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ
-------------------------------------

В Render.com перейдите в "Environment" и добавьте:

1. BOT_TOKEN
   Key: BOT_TOKEN
   Value: ваш_токен_из_BotFather

2. CHANNEL_ID
   Key: CHANNEL_ID
   Value: -1001234567890 (ваш ID канала)

3. CHECK_INTERVAL (опционально)
   Key: CHECK_INTERVAL
   Value: 1800

4. MAX_NEWS_PER_CYCLE (опционально)
   Key: MAX_NEWS_PER_CYCLE
   Value: 5

5. Нажмите "Save Changes"
6. Готово!

================================================================

ШАГ 9: ЗАПУСТИТЕ ДЕПЛОЙ
-------------------------

1. Нажмите "Create Worker"
2. Дождитесь завершения сборки (2-5 минут)
3. Проверьте логи
4. Готово!

================================================================
                     ЧАСТЬ 3: ПРОВЕРКА
================================================================

ШАГ 10: ПРОВЕРЬТЕ РАБОТУ БОТА
-------------------------------

1. Откройте чат с ботом в Telegram
2. Отправьте /status
3. Бот должен ответить статусом
4. Отправьте /news для ручного сбора новостей
5. Готово!

================================================================
                     ЧАСТЬ 4: ГОТОВО!
================================================================

ПОЗДРАВЛЯЕМ! Теперь ваш бот работает в облаке 24/7!

Что делает бот:
- Каждые 30 минут собирает новости из 28+ источников
- Фильтрует по тематике (технологии, игры, компьютеры)
- Публикует в ваш канал от вашего имени
- Поддерживает текст, фото и видео

Управление ботом:
- /start - Приветствие
- /status - Статус бота
- /news - Ручной сбор новостей

================================================================
                   РЕШЕНИЕ ПРОБЛЕМ
================================================================

ПРОБЛЕМА: Бот не запускается

РЕШЕНИЕ:
1. Проверьте логи в Render.com
2. Убедитесь, что BOT_TOKEN и CHANNEL_ID установлены
3. Проверьте, что бот добавлен в канал

ПРОБЛЕМА: Бот не публикует новости

РЕШЕНИЕ:
1. Проверьте ID канала
2. Убедитесь, что бот администратор канала
3. Проверьте права на публикацию

ПРОБЛЕМА: Ошибки в логах

РЕШЕНИЕ:
1. Перейдите в "Logs" в Render.com
2. Найдите ошибки
3. Исправьте проблему
4. Перезапустите
