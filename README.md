# 🤖 Auto-Telegram AI Bot — Полная инструкция

## Что это?
Автономный бот, который автоматически публикует статьи об ИИ и технологиях в твой Telegram-канал. Всё бесплатно!

**Стек технологий:**
- 🧠 **Groq API** — генерация текстов (бесплатно, 14,400 запросов/день)
- 🎨 **Pollinations.ai** — генерация картинок (бесплатно, без API-ключа)
- ☁️ **Render.com** — бесплатный сервер (работает 24/7)
- 📱 **Telegram Bot API** — публикация в канал

---

## 📋 Пошаговая настройка (≈20 минут)

### ШАГ 1: Создаём Telegram-канал и бота (5 минут)

#### 1.1 Создай канал
1. Открой Telegram
2. Нажми «Новый канал» → придумай название (например, «AI Daily»)
3. Сделай канал **публичным** (нужен @username, например @ai_daily_news)
4. Запомни @username канала — он понадобится

#### 1.2 Создай бота через @BotFather
1. Найди в Telegram бота **@BotFather**
2. Отправь команду `/newbot`
3. Придумай имя бота (например, «AI Publisher Bot»)
4. Придумай username бота (должен оканчиваться на `bot`, например `ai_publisher_bot`)
5. **BotFather выдаст токен** — выглядит так:
   ```
   123456789:ABCdefGHIjklMNOpqrsTUVwxyz1234567890
   ```
6. **Сохрани токен!** Это пароль от бота.

#### 1.3 Добавь бота администратором канала
1. Зайди в настройки канала → «Администраторы»
2. Добавь своего бота
3. Дай права: **Публикация сообщений** ✅

---

### ШАГ 2: Получи API-ключ Groq (3 минуты)

1. Перейди на [console.groq.com](https://console.groq.com)
2. Зарегистрируйся (можно через Google)
3. Перейди в раздел **API Keys**
4. Нажми «Create API Key»
5. **Скопируй ключ** — выглядит так:
   ```
   gsk_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

> 💡 Бесплатный тариф: 30 запросов/мин, 14,400 запросов/день. Для 4 постов/день — более чем достаточно!

---

### ШАГ 3: Загрузи бота на Render.com (10 минут)

#### 3.1 Создай аккаунт на Render
1. Перейди на [render.com](https://render.com)
2. Зарегистрируйся через GitHub (рекомендуется) или email

#### 3.2 Создай репозиторий на GitHub
1. Зайди на [github.com](https://github.com)
2. Создай новый репозиторий (назови `ai-telegram-bot`)
3. Загрузи туда файлы из этого архива:
   - `main.py`
   - `requirements.txt`
   - `Dockerfile`
   - `render.yaml`

> 💡 Если не умеешь работать с Git — просто нажми «Add file» → «Upload files» на GitHub

#### 3.3 Подключи Render к GitHub
1. В панели Render нажми **「New +」** → **「Background Worker」**
2. Выбери **「Build and deploy from a Git repository」**
3. Подключи свой GitHub-аккаунт
4. Выбери репозиторий `ai-telegram-bot`

#### 3.4 Настрой переменные окружения (ВАЖНО!)
В панели Render найди раздел **「Environment」** и добавь 3 переменные:

| Переменная | Значение | Пример |
|------------|----------|--------|
| `TELEGRAM_BOT_TOKEN` | Токен от @BotFather | `123456789:ABCdef...` |
| `TELEGRAM_CHANNEL_ID` | @username канала | `@ai_daily_news` |
| `GROQ_API_KEY` | Ключ от Groq | `gsk_xxxxxxxx...` |

> ⚠️ **Важно:** Значения вводи БЕЗ кавычек!

#### 3.5 Запусти бота
1. Нажми **「Create Background Worker」**
2. Render начнёт сборку (≈2-3 минуты)
3. Посмотри логи — если видишь «🤖 Бот запущен!» — всё работает!

---

### ШАГ 4: Проверь работу (2 минуты)

#### Тестовый запуск
1. В панели Render найди раздел **「Shell」**
2. Введи команду:
   ```bash
   export BOT_MODE=once && python main.py
   ```
3. Если в канале появился пост — бот работает!

#### Верни режим планировщика
В переменных окружения Render убедись, что:
```
BOT_MODE=scheduler
```

## ⚙️ Настройка расписания

По умолчанию бот публикует в:
- **08:00 МСК** (05:00 UTC)
- **12:00 МСК** (09:00 UTC)
- **16:00 МСК** (13:00 UTC)
- **20:00 МСК** (17:00 UTC)

### Как изменить?
Открой `main.py` и найди строку:
```python
PUBLISH_SCHEDULE = [5, 9, 13, 17]  # UTC время
```

Примеры:
```python
# 3 раза в день: 10:00, 15:00, 20:00 МСК
PUBLISH_SCHEDULE = [7, 12, 17]

# Каждый час
PUBLISH_SCHEDULE = list(range(24))

# 2 раза в день: утро и вечер
PUBLISH_SCHEDULE = [6, 18]
```

> 💡 МСК = UTC + 3 (летнее время) или UTC + 2 (зимнее)

## 🐛 Решение проблем

### Проблема: Бот не публикует посты
**Решение:**
1. Проверь логи в Render (раздел «Logs»)
2. Убедись, что бот добавлен администратором канала
3. Проверь правильность `TELEGRAM_CHANNEL_ID` (должен начинаться с `@`)

### Проблема: Groq API ошибка 429 (Rate Limit)
**Решение:**
- Это нормально при частых запросах. Бот автоматически ждёт 60 секунд и повторяет.
- Если часто — уменьши частоту публикаций в `PUBLISH_SCHEDULE`

### Проблема: Картинки не загружаются
**Решение:**
- Pollinations.ai иногда перегружен. Бот автоматически отправит пост без картинки.
- Через некоторое время картинки снова будут работать.

### Проблема: Render останавливает бота
**Решение:**
- На бесплатном тарифе Render может останавливать неактивные сервисы.
- Бот автоматически просыпается по расписанию!
- Если не просыпается — настрой внешний пинг (например, через UptimeRobot, тоже бесплатно)

## 🎨 Кастомизация

### Добавь свои темы
Открой `main.py` и найди список `ARTICLE_TOPICS`. Добавь свои:
```python
ARTICLE_TOPICS = [
    "Твоя тема 1",
    "Твоя тема 2",
    # ... существующие темы
]
```

### Измени стиль статей
Найди переменную `SYSTEM_PROMPT` и отредактируй правила генерации.

### Измени размер картинок
Найди функцию `get_pollinations_url` и измени `width` и `height`.
