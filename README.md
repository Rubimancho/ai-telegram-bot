# Полная инструкция по настройке Telegram бота для новостей

## Что делает этот бот?

Бот автоматически собирает новости о технологиях, играх и компьютерной тематике из различных источников на русском языке и публикует их в ваш Telegram канал от вашего имени.

---

## Часть 1: Подготовка

### Шаг 1: Установите Python

1. Перейдите на сайт: https://www.python.org/downloads/
2. Нажмите кнопку "Download Python 3.x.x" (последняя версия)
3. Запустите скачанный файл установщика
4. **ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"** (самое важное!)
5. Нажмите "Install Now"
6. Дождитесь завершения установки

**Проверка:** Откройте терминал (Terminal на Mac, CMD или PowerShell на Windows) и введите:
```
python --version
```
Должно появиться: `Python 3.x.x`

### Шаг 2: Установите Node.js (если нет)

Скачайте с https://nodejs.org/ и установите LTS версию.

## Часть 2: Создание Telegram бота

### Шаг 1: Найдите @BotFather

1. Откройте Telegram на телефоне или компьютере
2. В поиске введите: `@BotFather`
3. Нажмите на него и начните чат

### Шаг 2: Создайте нового бота

Отправьте команду:
```
/newbot
```

Бот попросит вас:
1. **Введите имя бота** - например: `Мои Техно Новости`
2. **Введите username бота** - должен заканчиваться на `bot`, например: `my_tech_news_bot`

После создания бот пришлет вам **токен** - длинную строку вида:
```
1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
```

**СОХРАНИТЕ ЭТОТ ТОКЕН!** Он понадобится позже.

### Шаг 3: Создайте канал

Если у вас еще нет канала:

1. В Telegram нажмите "Написать" (карандаш)
2. Выберите "Новый канал"
3. Введите название канала
4. Введите username канала (латиницей)
5. Выберите тип: Публичный канал
6. Готово!

### Шаг 4: Добавьте бота в канал

1. Откройте настройки канала (три точки в правом верхнем углу)
2. Выберите "Администраторы"
3. Нажмите "Добавить администратора"
4. Введите username вашего бота (без @)
5. Выберите бота из списка
6. **Включите разрешение "Публикация сообщений"**
7. Нажмите "Сохранить"

### Шаг 5: Узнайте ID канала

**Способ 1 (самый простой):**
1. Перешлите любое сообщение из канала боту `@userinfobot`
2. Бот пришлет информацию, где будет `Forwarded from chat: -1001234567890`
3. Скопируйте этот ID

**Способ 2:**
1. Перешлите сообщение из канала боту `@getidsbot`
2. Скопируйте `Chat ID`

**Способ 3:**
1. Откройте канал в веб-версии Telegram
2. Посмотрите на URL: `https://t.me/c/1234567890/1`
3. ID канала будет `-1001234567890` (добавьте `-100` к числу из URL)

## Часть 3: Настройка бота на компьютере

### Шаг 1: Откройте терминал

**На Mac:**
- Нажмите Cmd + Пробел
- Введите "Terminal"
- Нажмите Enter

**На Windows:**
- Нажмите Win + R
- Введите `cmd`
- Нажмите Enter

### Шаг 2: Перейдите в папку бота

```bash
cd ~/telegram-news-bot
```

**Если папки нет:**
```bash
mkdir ~/telegram-news-bot
cd ~/telegram-news-bot
```

### Шаг 3: Установите зависимости

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

На Windows вместо `source venv/bin/activate` используйте:
```bash
venv\Scripts\activate
```

### Шаг 4: Настройте токен бота

Создайте файл `.env` в папке бота:

**На Mac:**
```bash
touch .env
open .env
```

**На Windows:**
```bash
notepad .env
```

Вставьте в файл:
```
BOT_TOKEN=ваш_токен_бота_здесь
CHANNEL_ID=-1001234567890
```

Замените `ваш_токен_бота_здесь` на ваш токен из @BotFather.
Замените `-1001234567890` на ID вашего канала.

Сохраните файл.

## Часть 4: Запуск бота

### Шаг 1: Запустите бота

```bash
python3 bot.py
```

Вы должны увидеть сообщение:
```
Application started
```

### Шаг 2: Управление ботом

Откройте чат с вашим ботом в Telegram и отправьте команды:

**Начать работу:**
```
/start
```

**Запустить автоматическую публикацию:**
```
/run
```

**Остановить публикацию:**
```
/stop
```

**Получить новости вручную:**
```
/news
```

**Проверить статус:**
```
/status
```

## Часть 5: Автоматический запуск (опционально)

Чтобы бот работал постоянно, даже когда закрыт терминал:

### На Mac:

1. Установите pm2:
```bash
npm install pm2 -g
```

2. Запустите бота:
```bash
pm2 start bot.py --name "news-bot"
```

3. Автозапуск при загрузке:
```bash
pm2 startup
pm2 save
```

### На Windows:

1. Установите pm2-windows-startup:
```bash
npm install pm2-windows-startup -g
pm2-startup install
```

2. Запустите бота:
```bash
pm2 start bot.py --name "news-bot"
pm2 save
```

## Решение проблем

### Проблема: "command not found: python"

Решение:
```bash
python3 --version
```
Используйте `python3` вместо `python`.

### Проблема: "No module named 'telegram'"

Решение:
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### Проблема: "BOT_TOKEN is not set"

Решение: Проверьте, что файл `.env` существует и содержит правильный токен.

### Проблема: Бот не публикует новости

Решение:
1. Проверьте, добавлен ли бот как администратор канала
2. Проверьте ID канала
3. Убедитесь, что бот имеет права на публикацию

### Проблема: "Permission denied"

Решение:
```bash
chmod +x bot.py
```

## Часто задаваемые вопросы

**Q: Бот работает только на моем компьютере?**
A: Да, бот работает на вашем компьютере. Чтобы он работал постоянно, используйте pm2 или разверните его на сервере.

**Q: Можно ли изменить интервал публикации?**
A: Да, отредактируйте файл `config.py` и измените `CHECK_INTERVAL`.

**Q: Можно ли добавить другие источники новостей?**
A: Да, отредактируйте файл `sources.py` и добавьте новые RSS-ленты или сайты.

**Q: Бот публикует от моего имени или от имени канала?**
A: Бот публикует от имени канала, но пользователи видят, что это ваш канал.

**Q: Как остановить бота?**
A: Отправьте `/stop` боту в Telegram или нажмите Ctrl+C в терминале.
