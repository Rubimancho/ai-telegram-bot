================================================================
      ПОЛНАЯ ИНСТРУКЦИЯ ПО НАСТРОЙКЕ TELEGRAM БОТА
              ДЛЯ АВТОМАТИЧЕСКОЙ ПУБЛИКАЦИИ НОВОСТЕЙ
================================================================

Данная инструкция поможет вам создать и настроить Telegram бота, 
который будет автоматически собирать и публиковать новости о 
технологиях, играх и компьютерной тематике в ваш канал.

================================================================
                        ЧАСТЬ 1: ПОДГОТОВКА
================================================================

ШАГ 1: УСТАНОВКА PYTHON
------------------------

1. Перейдите на сайт: https://www.python.org/downloads/

2. Нажмите кнопку "Download Python 3.x.x" (последняя версия)

3. Запустите скачанный файл установщика

4. ОБЯЗАТЕЛЬНО поставьте галочку "Add Python to PATH"
   (это очень важно, без этого ничего не заработает!)

5. Нажмите "Install Now"

6. Дождитесь завершения установки

ПРОВЕРКА:
  Откройте терминал и введите:
  
  python --version
  
  Должно появиться: Python 3.x.x


ШАГ 2: УСТАНОВКА NODE.JS (если нет)
-------------------------------------

1. Перейдите на сайт: https://nodejs.org/

2. Скачайте LTS версию

3. Установите, следуя инструкциям установщика


================================================================
                    ЧАСТЬ 2: СОЗДАНИЕ БОТА
================================================================

ШАГ 1: НАЙДИТЕ @BotFather
---------------------------

1. Откройте Telegram на телефоне или компьютере

2. В поиске введите: @BotFather

3. Нажмите на него и начните чат


ШАГ 2: СОЗДАЙТЕ НОВОГО БОТА
-----------------------------

Отправьте команду:

  /newbot

Бот попросит вас:

1. Введите имя бота - например: "Мои Техно Новости"

2. Введите username бота - должен заканчиваться на "bot"
   Например: my_tech_news_bot

После создания бот пришлет вам ТОКЕН - длинную строку вида:

  1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

ВАЖНО: СОХРАНИТЕ ЭТОТ ТОКЕН! Он понадобится позже.


ШАГ 3: СОЗДАЙТЕ КАНАЛ
-----------------------

Если у вас еще нет канала:

1. В Telegram нажмите "Написать" (карандаш)

2. Выберите "Новый канал"

3. Введите название канала

4. Введите username канала (латиницей)

5. Выберите тип: Публичный канал

6. Готово!


ШАГ 4: ДОБАВЬТЕ БОТА В КАНАЛ
------------------------------

1. Откройте настройки канала (три точки в правом верхнем углу)

2. Выберите "Администраторы"

3. Нажмите "Добавить администратора"

4. Введите username вашего бота (без @)

5. Выберите бота из списка

6. Включите разрешение "Публикация сообщений"

7. Нажмите "Сохранить"


ШАГ 5: УЗНАЙТЕ ID КАНАЛА
--------------------------

СПОСОБ 1 (самый простой):

1. Перешлите любое сообщение из канала боту @userinfobot

2. Бот пришлет информацию, где будет:
   Forwarded from chat: -1001234567890

3. Скопируйте этот ID

СПОСОБ 2:

1. Перешлите сообщение из канала боту @getidsbot

2. Скопируйте "Chat ID"

СПОСОБ 3:

1. Откройте канал в веб-версии Telegram

2. Посмотрите на URL: https://t.me/c/1234567890/1

3. ID канала будет: -1001234567890
   (добавьте -100 к числу из URL)


================================================================
                ЧАСТЬ 3: НАСТРОЙКА НА КОМПЬЮТЕРЕ
================================================================

ШАГ 1: ОТКРОЙТЕ ТЕРМИНАЛ
--------------------------

На Mac:
  Нажмите Cmd + Пробел
  Введите "Terminal"
  Нажмите Enter

На Windows:
  Нажмите Win + R
  Введите cmd
  Нажмите Enter


ШАГ 2: ПЕРЕЙДИТЕ В ПАПКУ БОТА
-------------------------------

В терминале введите:

  cd ~/telegram-news-bot

Если папки нет:

  mkdir ~/telegram-news-bot
  cd ~/telegram-news-bot


ШАГ 3: УСТАНОВИТЕ ЗАВИСИМОСТИ
-------------------------------

В терминале введите:

  python3 -m venv venv

  source venv/bin/activate

  pip install -r requirements.txt

На Windows вместо "source venv/bin/activate" используйте:

  venv\Scripts\activate


ШАГ 4: НАСТРОЙТЕ ТОКЕН БОТА
-----------------------------

1. Создайте файл .env в папке бота

На Mac:
  touch .env
  open .env

На Windows:
  notepad .env

2. Вставьте в файл:

BOT_TOKEN=ваш_токен_бота_здесь
CHANNEL_ID=-1001234567890

3. Замените "ваш_токен_бота_здесь" на ваш токен из @BotFather

4. Замените "-1001234567890" на ID вашего канала

5. Сохраните файл


================================================================
                       ЧАСТЬ 4: ЗАПУСК
================================================================

ШАГ 1: ЗАПУСТИТЕ БОТА
----------------------

В терминале введите:

  python3 bot.py

Вы должны увидеть сообщение:
  Application started


ШАГ 2: УПРАВЛЕНИЕ БОТОМ
------------------------

Откройте чат с вашим ботом в Telegram и отправьте команды:

/start     - Начать работу бота
/run       - Запустить автоматическую публикацию
/stop      - Остановить публикацию
/news      - Получить новости вручную
/status    - Проверить статус бота


================================================================
             ЧАСТЬ 5: АВТОМАТИЧЕСКИЙ ЗАПУСК (опционально)
================================================================

Чтобы бот работал постоянно, даже когда закрыт терминал:

НА MAC:

1. Установите pm2:
   npm install pm2 -g

2. Запустите бота:
   pm2 start bot.py --name "news-bot"

3. Автозапуск при загрузке:
   pm2 startup
   pm2 save


НА WINDOWS:

1. Установите pm2-windows-startup:
   npm install pm2-windows-startup -g
   pm2-startup install

2. Запустите бота:
   pm2 start bot.py --name "news-bot"
   pm2 save


================================================================
                    РЕШЕНИЕ ПРОБЛЕМ
================================================================

ПРОБЛЕМА: "command not found: python"

  Решение:
  python3 --version
  
  Используйте python3 вместо python


ПРОБЛЕМА: "No module named 'telegram'"

  Решение:
  source venv/bin/activate
  pip install -r requirements.txt


ПРОБЛЕМА: "BOT_TOKEN is not set"

  Решение: Проверьте, что файл .env существует 
  и содержит правильный токен


ПРОБЛЕМА: Бот не публикует новости

  Решение:
  1. Проверьте, добавлен ли бот как администратор канала
  2. Проверьте ID канала
  3. Убедитесь, что бот имеет права на публикацию


ПРОБЛЕМА: "Permission denied"

  Решение:
  chmod +x bot.py

================================================================
                  ЧАСТО ЗАДАВАЕМЫЕ ВОПРОСЫ
================================================================

В: Бот работает только на моем компьютере?

О: Да, бот работает на вашем компьютере. Чтобы он работал 
   постоянно, используйте pm2 или разверните его на сервере.


В: Можно ли изменить интервал публикации?

О: Да, отредактируйте файл config.py и измените 
   CHECK_INTERVAL (в секундах).


В: Можно ли добавить другие источники новостей?

О: Да, отредактируйте файл sources.py и добавьте новые 
   RSS-ленты или сайты.


В: Бот публикует от моего имени или от имени канала?

О: Бот публикует от имени канала, но пользователи видят, 
   что это ваш канал.


В: Как остановить бота?

О: Отправьте /stop боту в Telegram или нажмите Ctrl+C 
   в терминале.
